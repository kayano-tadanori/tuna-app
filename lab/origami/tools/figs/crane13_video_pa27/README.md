## 見えた事実（3か所とも同じ順番）

1. **まず脚の先を、8層まとめて外へ折る**（10:11–10:13）。⑬の線で、脚の先が1つのかたまりのまま
   外側（脚の側面の向き）へ約90°〜130°振り出される。この時点で胴は閉じたまま（左手の人差し指が胴を押さえている）。
   → 既存 engine が唯一通していた「**先の8層をひとかたまりで外へ折る**」は、実物の第1工程そのもの。
2. **胴の片側の層を開く**（10:14.0–10:14.5）。付け根のところで胴の右側の層が持ち上がり、脚の先と胴の間に隙間ができる（原寸2枚目の1〜3コマ）。
3. **脚の先を、開いた層の間へ差し込み、胴を閉じる**（10:14.5–10:15.3）。差し込みながら脚の先は
   さらに上向きに回り、最後に胴の両層のあいだで挟まれて止まる。先端は胴の右上へ突き出る。
4. そのあと「折った角度を合わせます」（10:20〜）で、もう1本と角度をそろえ直す。
5. **頭の字幕（11:46）＝「開きながら、角度をつけて折ります」**。頭でも手順は同じ：先を外へ折る（11:37–11:41）→ 首の層を指で開く（11:42–11:45）→ 差し込む（11:45–11:48）。

## 推論（事実から導けるが、動画で直接は見えていない）

- 工程1の「外へ折る」で ⑬ の折り目が**8層すべてに同時に**付く。両側の層が重なったまま折るので、
  開いたときは中心線をはさんで鏡映＝本人が第8段で見つけた「**へ**」の字はこれ。
- 工程2〜3で、脚の各層は工程1で付けた折り目の位置で折れ直る。**新しい折り目は増えない**（差し込んだあとの外形に
  余分な折り目は見えない。9/16の動画の観察 4:59–5:03 とも一致）。
- 工程2で胴が開くあいだ、紙は板のままではない（持ち上がった層は付け根で少したわんで見える）。
  **途中の姿は剛体運動ではない可能性が高い**。ただし出発（工程1のあと）と終端（工程3のあと）は平ら。

## 見えていないこと（推測で埋めない）

- 工程2〜3の途中で、脚の**内側の層**（8層のうち胴に近い側）がどう動くかは指の陰。
- 胴の開き方が「片側の層だけ」か「両側とも少し」かは、この角度のカメラでは断定できない（右側が開くのは見える）。
- 工程1の振り出し角度の正確な値（90°で止めるのか、それ以上か）。

## 第20段（9/18 の保留）との関係

- 剛体1本の連続運動で出発→終端をつなぐ必要は、この観察から**無い**。実物は「外へ折る（折り目づけ）→開く→差し込む→閉じる」の
  段階的な操作で、途中は開いた状態を経る。
- 次の設計の候補（未決定・本人承認待ち）：工程1＝既存の fold（8層フラップ・外へ）→ crease に戻す／工程2＝既存の「背を開く」の系統／
  工程3＝開いた紙の上で、⑬の折り目に沿って各層を折り直す／閉じる。**エンジンに新しい運動を足す前に、既存操作の組み合わせで通るかを先に確かめる**。

## 本人の実物模型（IMG_3409.mov・2026-09-18・12秒・1枚の紙）

`own_IMG_3409_0-7s_2fps.png`／`own_IMG_3409_7-12s_2fps.png`。1枚の紙に**中心線1本＋中心線上の1点で鏡に曲がる⑬の線（「へ」）**を書いた模型。
見えた動き：①中心線で山に折って V に開く（0–3秒）→ ②V を開いたまま、下の部分を指で押して中心線の下半分を谷へ反転させ、⑬の線2本が同時に折れる（3–9秒）
→ ③閉じると、反転した部分が両側の紙のあいだに挟まって先が突き出る（9–12秒）。
= **degree-4 の頂点1つ・1枚（2層）の古典的な中割り**（`check_reversefold_reference.py` が剛体で成立と出した形と同じ）。
YouTube 動画の工程②③（開く→差し込む→閉じる）の中身がこれ。工程①（外へ折る）は線を8層へ一度に付けるための手で、この模型では線を先に書いたので省かれている。
⚠線の角度は動画から読まない（原則どおり）。
