## 非貫通の保証の範囲（2回目の周囲の紙）
**全角度の論証を使える部分**（`check_petal_fold.py` [4b]：u=tan(θ/2)∈(0,∞) で符号を厳密に判定）
- モデルの10面の中：動く面は θ∈(0,π) で z>0（軸の線の上だけ z=0）、動く面どうし・動く面とモデルの止まる4面の交わりは共有の辺・点だけ（厚み0）。
- 2回目にも移せる理由：裏の2層はモデルに、素材の対称 D と**向きを保つ**平面の等長変換 G で重なる（G は z の符号を変えない）。まとまりの面はモデルの三角形の一部なので同じ運動・同じ符号。
- 周囲の止まった紙はぜんぶ z=0 の平面にある。動く面は軸の線を除いて z>0 なので、周囲の紙と会えるのは軸の線の上だけ → 残る条件は「出発の上下」と「軸上の接触」（本体の門 ⑤⑥、Python (a)(b)）に帰着する。

**未保証の部分**
- (c) の非貫通は **32分割の数値確認**（θ=kπ/32 の標本・辺が面を突き抜けるかの判定・許容差 1e-9／1e-7）。標本のあいだの角度は、上の論証に頼っていて、周囲の紙を含めた全角度の厳密な証明はしていない。
- (b) の軸上の接触も、Python は4本の軸×64点×両側の**標本**（本体の⑥は「面は凸・重なる組の上下は一定」を前提に、共有区間の中点1点で比べる）。
- 厚み0の抽象：同じ平面に接すること（z=0 での重なり・着地の瞬間）は突き抜けと数えない。紙の厚みによる食い込みは扱わない。
- 着地（θ=π）の周囲の紙との上下は、θ=π(1−ε)（ε 5段）の高さによる数値の決定。

## 重複の整理
- まとまりの条件：以前は「重心が三角形の中の面を集める → はみ出し → 面積」と、同じ性質（ちょうど敷きつめる）を2か所で守っていた。**「三角形と面積で重なる面は、ぜんぶ中に収まり、合わせてちょうど敷きつめる」の1つ**にした（重心による推測もなくなった）。壊すと既存の「上の三角なし」の理由の検査で鳴る（G373）。
- 本体の門と Python の照合は**別の実装で同じ性質を見る**（片方の書き違いをもう片方が拾う）ので、重複として消していない。
- 非貫通は本体に門を足していない。厚み0の前提（動く面は z≥0・止まった紙は z=0）で、⑤⑥が守る範囲に入る。独立の照合 (c) が、その前提が崩れたら鳴ることを G376 で確かめた。
