背の可視判定の計測（engine だけ・画面の操作はしない）

自由折りの画面（freefold3d.html）とは別のページです。原本の保存も画面の状態も触りません。
「計測する」を押すと、じゃばら折り（16・32・64面）で、次を5回ずつ測って中央値を出します。

  • 区間 初回＝紙を作り直した直後の hingeIntervals（可視判定を全部計算する）
  • 区間 再利用＝同じ紙でもう一度（ためた結果を使う）
  • 背を選ぶ＝pointerdown と同じ pickVisibleHinge（紙を作り直した直後）
  • 開く提案＝背を選んだあとの proposeOpen（断る形でも時間は同じ道を通る）
  • 辺ドラッグ1コマ＝辺をつかんで運ぶときに毎コマ呼ぶ edgeToHingeOptions
携帯実機で開く手順
  1. PC と携帯を同じ Wi‑Fi につなぐ。
  2. PC でこの tools フォルダを開き、アドレス欄に cmd と入れて Enter →
    python -m http.server 8800 --bind 0.0.0.0（Windows の「ネットワークへのアクセスを許可」が出たら、プライベートネットワークを許可）。
  3. 別の cmd で ipconfig → Wi‑Fi の「IPv4 アドレス」（例 192.168.1.23）を見る。
  4. 携帯のブラウザで http://（IPv4アドレス）:8800/bench_hinge.html を開き、「計測する」。画面を消さずに待つ。
  5. 下に出た文字（機種の名前つき）をコピーして送る。終わったら PC の cmd で Ctrl+C（サーバーを止める）。

⚠古いファイルが残って見えるときは、携帯のブラウザの「シークレット（プライベート）タブ」で開く。
