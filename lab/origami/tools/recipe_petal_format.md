## 1手の形

```json
{
 "id": "s9", "diagramStep": "8-9", "op": "petal", "instruction": "…",
 "model": "petal-rhombus-67.5",
 "base":   { "faceId": "<花弁の右半分の面>" },
 "pivots": [ P, P' ],
 "axes": [
  { "from": P', "to": P, "role": "drive" },
  { "vertex": P,  "end": Q3,  "role": "petal-kite" },
  { "vertex": P,  "end": B,   "role": "side-hinge" },
  { "vertex": P,  "end": Q2R, "role": "fixed-kite" },
  { "vertex": P,  "end": O,   "role": "fixed-fold" },
  { "vertex": P', "end": Q3,  "role": "petal-kite" },
  { "vertex": P', "end": A,   "role": "side-hinge" },
  { "vertex": P', "end": Q2L, "role": "fixed-kite" },
  { "vertex": P', "end": O,   "role": "fixed-fold" }
 ],
 "branch": { "linkage": "tan-half-cos67.5", "name": "petal", "sideFold": "toward-petal-underside",
             "drive": { "fromDeg": 0, "toDeg": 180 } },
 "stack": [ ["<下の面>", "…", "<上の面>"], … ]
}
```

## 各項目の意味

| 項目 | 意味 |
|---|---|
| 座標 | すべて**素材座標**（原紙 [-1,1]²）。袋折りの `vertex`/`end` と同じ。つるの1回目では P=(2-√2, 0)、P'=(0, -(2-√2))、Q3=(1,-1)、Q2R=(1,1)、Q2L=(-1,-1)、B=(1,0)、A=(0,-1)、O=(0,0) |
| `pivots` | 2つの連動する頂点。`[右, 左]`。右＝`base` の面が持つほう |
| `base.faceId` | 花弁の右半分（頂点 Q3・M・P を持つ面）。面の集まり（花弁2面・脇4面）は保存しない。**再生のたびに**結びとこの軸から集め直す。🧩（2026-09-15）余分な折り目で花弁の右半分が複数の面に分かれているときは、その**まとまり**（素材で三角形 Q3・M・P をちょうど敷きつめ、同じ置かれ方で、平らな折り目だけでつながる面）の1面。書き手は faceId の順で最初の面を書き、読み手はまとまりの中の面なら受け入れる。**形式は変えていない** |
| `drive` | 花弁が回る軸。素材上 P'→P。**向きの約束**：θ>0 で開いた角 Q3 が紙面の手前（+z）へ上がる。素材→置き場の写像で向きが反転していても、この約束で決める |
| `petal-kite` | 花弁と一番上の層の脇の三角の境。素材上は花弁の四分円の中の線 |
| `fixed-kite` | 2枚目の脇の三角と止まる紙の境。正方基本形では `petal-kite` と**同じ線に重なる**が、素材上は別の線（隣の四分円） |
| `side-hinge` | 一番上の脇と2枚目の脇の境（折れた背。終端で開いて平らになる） |
| `fixed-fold` | 止まる紙どうしの背（P-O）。動かない。4本の軸の菱形（67.5°）が成り立つことの照合用 |
| `linkage` | `tan(φ/2) = cos67.5°·tan(θ/2)`。袋折りの `tan(γ1/2)tan(γ2/2)=1/cosα` を α=67.5° にしたもの |
| `name: "petal"` | 3本ある枝のうち**花弁折りの枝**だけを許す。ほかの枝は断る：`kite`（θ≡0 のまま T1 と S2 が同じ角で起きる＝凧形の折り）、`sides-folded`（φ≡π のまま θ だけ動く） |
| `sideFold` | 下の「sideFold と終端の上下」 |
| `drive` の範囲 | 0°→180° だけ。両端は特異点（0° で `kite` と、180° で `sides-folded` と交わる） |
| `stack` | **検算値**。重なる領域ごとに面を**下から**並べる（袋折りと同じ向き）。再生で計算した上下と1つでも違えば断る。**stack の順で計算結果を上書きしない** |

## sideFold と「終端で脇が花弁の上に来る」の関係

- `toward-petal-underside`＝一番上の層の脇の三角（T1R・T1L）は、**花弁の下面の側**へ折れる。
  - 下面＝θ=0 のとき下の紙に接していた花弁の面。つるの1回目では素材の**表**（白）。
- 花弁は θ=0→180° で裏返る。そのため下面は、終端では**上を向く**。
- だから脇の三角は、終端で**花弁の上**に来る。上に見えるのは脇の三角の素材の**裏**（赤）。
- この向きは自由に選べない。閉路が閉じる符号は θ>0 で1通りだけ（`check_petal_fold.py` [2]）。
  - 記録しているのは、再生で計算した向きが本当にこれかを照合するため。
  - `behind-petal`（前回の案）は、この関係を曖昧にするので使わない。

## 再生で確かめること（実装するときの関門）

1. `pivots` の2点・`axes` の8本が、いまの紙の折り目・背・面の辺と素材上で一致する。
2. 役割ごとに、結びの種類（平ら／180°）が直前の状態と合う。
   - `petal-kite`・`fixed-kite`・`drive`＝平ら
   - `side-hinge`・`fixed-fold`＝180°
3. 花弁の2面が、`drive` の線の同じ側で平らな結び（Q3-M）でつながっている。
4. 置かれ方が検証モデルの θ=0 と一致する（袋折りの局所照合と同じ考え方）。
5. 周囲の紙：出発時に、動く面と面積で重なる止まった紙はぜんぶ下。軸の一周で、軸の層より上の止まった紙が触れていない。
6. 終端の上下を計算し、`stack` と照合する。

## 照合の根拠（2026-09-15）

- **幾何**：`check_petal_fold.py` 59項目。閉路・結び・枝・非貫通の符号条件は厳密。終端の上下は、高さの1次の係数の符号で厳密（区画分けは浮動小数）。
- **動画**（YouTube bheH5wZckps・1回目 2:38〜3:21、2回目 3:22〜3:41）の照合は、次の2つを分けて記録する。
  - 見えた事実
    - 持ち上げた面の内側は白。
    - 左右の脇は花弁の白い側へ畳まれ、3:05 に赤い脇が白い面の上へ重なっていく。
    - 終端は上が全部赤。花弁の部分の中心に、白の細い線が見える。
  - 導いたこと
    - 上が赤なら、花弁（裏返って白が上）の上に脇が乗っている。これは [4e] の `T1R裏 > T2R表` と一致する。
    - 下の層の順（T2 と T3・G2 の間）は、動画では見えない。モデルの計算による。
- **動画との違い**：途中の紙は曲がっている（剛体の途中姿とは形が違う）。一致は、動く面・倒れる向き・終端の上から見える面と表裏まで。運動の途中の形の一致は主張しない。

## 🧩 折って開いた⑦からの花弁折り（2026-09-15・形式は無変更）
- 認識は面ではなく**まとまり**で行う：モデルの1面＝素材でその三角形をちょうど敷きつめ（包含と面積）、xf がそろい、中の結びが crease だけでつながる面の集まり。元の面・faceId・折り目は書きかえない。
- 層（③）・結び（④：モデルの12本は素材の区間を種類つきでちょうど覆う・動く面の結びはその12本かまとまりの中の折り目だけ）・出発（⑤）は、まとまりの面ごとに見る。
- 軸の一周（⑥）は、軸に触れる止まった紙とモデルの面が**面積で重なる点**（軸上の共有区間の中点のすぐ両脇）でだけ layer を比べる。背を開いた紙は層番号が詰め直されないので、重ならない面の番号は比べない。
- 運動の途中の見張り：動く面に触れる結びぜんぶ（余分な折り目も）を θ=kπ/16・両端と中点で、両側の運動が同じ所に置くか（`motionBondGap`）。
- 独立照合：`check_petal_engine.py` もまとまりを shapely で作り直し、運動の途中の結びの一致を別に数える。
