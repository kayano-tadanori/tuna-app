6. ⑭ 首の上から頭の線を引く（折り目にならない線でも可）→「この線で中割り」→ 首の先を指す（根元の頂点もいっしょに動く）→ 確定

## 1. 保存形式（v1 のまま op を1つ足す）
```json
{ "id":"s26","diagramStep":"26","op":"reverse","instruction":"中割り折りにする",
  "reference":{"faceId":"…"},"line":[[x,y],[x,y]],"movingSidePoint":[x,y],
  "targets":[{"faceId":"…","layerPath":[…]},…],
  "hinge":{"stepId":"s2","faceIds":["…","…"],"seg":[[x,y],[x,y]]} }
```
- line・movingSidePoint・targets・reference は fold と同じ意味と座標（基準面の素材座標・±1）。`kind` は持たない（山谷は入れ子で決まる）。`nest` は予約（書くと知らない項目で断る）。
- hinge.seg は**識別だけ**：再生では stepId＋faceIds で背を引き直し、その結びの素材線分と 1e-12 で一致しなければ断る。計算には使わない。
- θ＝先の側で測った鋭角（0°<θ≤90°）。原本には書かない（線から取る）。

## 2. 関門（再生の芯＝提案・確定・redo・保存の再生で同じ所を通る）
1. **背の照合**：hinge を引き直せない／seg が一致しない
2. **頂点**：線が背の線分の内側を横切らない（頂点が背の外）
3. **輪**：背の両側の集合（背の線の片側の内部へ入る結びだけをたどる）が、背の外でもつながる
4. **フラップ**：フラップが背でつながらない（背の両側のどちらにも入らない面がある）／両側に分かれない
5. **全層**：線で二つに分かれない面がフラップにある
6. **下に紙・裂け**：foldableSet の①④（各側は自分の内側へ折れる＝相手側の紙は障害に数えない）
- 提案だけの検査：途中48コマの**突き抜け**と、根元の頂点が動くときの**裂け**（結びの両端と中点）。はみ出しは断らない。

## 3. 背の根元の頂点へ開きを伝える規則（⑭で足した1つ）
背の区間の `reversedBy` の頂点が、区間の根元の端にある（＝根元が畳まれた degree-4 の中割りの頂点）とき、
この背の開き c に対して 根元の単独模型を **c⁻_root＝c・c⁺_root＝−c・tan(c/2)＝cosθ_root·tan(z_root/2)**（θ_root＝90° は z_root＝π）で動かす
（根元の中割りの運動を同じ式で巻き戻す）。根元の向こうは根元のブロックとして剛体で回る。2頂点の鎖・自由度1・閉じた式だけ。
開く向きは根元の運動に合わせる。根元の中割りのあとで根元のまわりが動いていたら断る。根元が普通の背なら発動しない。鎖は1段。

## 4. 入れ子の決め方（層は履歴＝order() が持つ）
重なり（面積あり）の組だけに上下を決め、いまの層番号を優先したトポロジカル順で振り直す：
止まる面どうし＝いまの順／下の側の止まる面 ＜ 動いた面 ＜ 上の側の止まる面／動いた面どうし＝下の側 ＜ 上の側・同じ側は順を逆に／
どちらの側でもない面＝元の番号どうし。輪になれば断る。頂点から先の背の区間に `reversedBy` を足す（表示の山谷は反転の偶奇で入れかえる）。

## 5. 画面の入口（freefold3d.html）
線モードで2点 →「この線で中割り」→ 先の側を指す → 背の候補（1本なら自動）→ 途中（engine の frame(t)）→ 確定。
折り目にならない線（折り目の関門で断られる細い所の線）も中割りの線としては受ける。動く側の印は、フラップの中で線から最も遠い頂点から画面が導く。
engine へ渡す線は同じ直線のまま長さ3にそろえる。どれも UI の導出だけで、engine の関門・定数は変えていない。

## 7. 既知の制限
- **見える背は開けない**：つる⑫の紙で、見える中心線の背（s6#1・s6#2・s7#2）は「背の軸の外でもつながる」で「背を開く」が断る。要る背（s2 の脚の区間）は見えない背で、画面の背つかみ（見える背だけ）では選べない。中割りは線から背の候補を出すので影響しない（第21段 §79）。
- **山で折った紙は「背を開く」で戻せない**（谷で折った紙は戻せる）。
- **鈍角の側は断る**：つかんだ側のくさびが90°を越えると、剛体では内側に入らず突き抜ける。反対側の先をつかむ（同じ線を先の側から測り直したもの）。
- かぶせ折り（nest outside）は未実装。Python の読み手は関門⑥と途中の検査を見ない（結果の照合用）。convert は reverse を断る。
