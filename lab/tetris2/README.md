## 中身（外部ライブラリ ゼロ）

| ファイル | 役割 |
|---|---|
| `js/gl.js` | WebGL2の土台（行列・シェーダ・FBO・立方体ジオメトリ） |
| `js/shaders.js` | GLSL。背景／ブロック／パーティクル／ポストプロセス |
| `js/renderer.js` | 描画パス一式（HDR → ブルーム → 合成） |
| `js/core.js` | ゲームロジック（描画を知らない層） |
| `js/audio.js` | WebAudio合成のみの音。BGMはレベルでレイヤーが増える |
| `js/chars.js` | 応援団（オトン・オカーン・チッチ・ジェイド）のボクセルデータと動き |
| `js/game.js` | 入力・演出・描画データの組み立て |

### 描画
- 自作WebGL2。ブロックは**インスタンシングで1ドロー**。頂点は普通の立方体24頂点で、
  面取り（ベベル）の陰影と枠のネオンは**フラグメントシェーダで擬似的に**作っている（モバイル対策）。
- HDR（RGBA16F）→ しきい値抽出 → 1/2・1/4のブラー → 横方向のアナモルフィック → ACESトーンマップ。
- 色収差・ビネット・グレイン・衝撃波のUV歪み・画面フラッシュは合成パスに統合（追加コストほぼゼロ）。
- 端末負荷に応じて**解像度を自動で上下**（`R.setQuality`）。`devicePixelRatio` は 1.75 で頭打ち。

### ゲーム性（元の実装から変えたところ）
- **7種袋**（元は純ランダム。Iが延々来ない理不尽をなくす）
- **SRS準拠の壁蹴り**＋**T-Spin判定**（3コーナー則）
- **ホールド**と**NEXT3つ**
- DAS/ARR（キーボード 133/33ms、タッチ 160/40ms）、ロックディレイ0.5秒＋15回リセット
- スコアはガイドライン準拠（B2B×1.5、コンボ50×n、パーフェクトクリア加算）
- 難易度3段（やさしい／ふつう／むずかしい）。やさしいは落下2倍ゆっくり・12ラインで1レベル

### BGMは2曲から選べる
- **オトン**（初期値）… 自作のネオン系。レベルが上がるとレイヤー（ベース→キック→ハット→パッド→アルペジオ→メロディ→スネア→リード）が増える。
- **コロブチカ**… いわゆる「テトリスのあのロシアっぽい曲」。**19世紀のロシア民謡（著作権切れ）**の旋律に、
  ベース・和音・ドラムをこちらで付けた自作の編曲。特定のゲームの編曲を写したものではない。
  BPM150。レベルでハット→和音→アルペジオ→ハモリが増えていく作りは共通。
- タイトル画面と、ポーズ中の「♪ 曲」ボタンで切りかえ（`localStorage` に記憶）。

### アイテム（本体のおとんテトリスと同じ2種）
- **💣 下2行を消す**… 下2行が爆発。破片＋オレンジの衝撃波リング＋低い炸裂音。コンボは切れる（自力で消していないため）。スコアもラインも増えない救済用。
- **🐢 15秒スロー**… 落下が1/3に。**ウェルのレールが水色に変わり、背景の流れが遅くなり、BGMのテンポも0.86倍に落ちる**。
  ボタンのふちが残り時間のリングになって減っていく。切れると小さく上昇音。
- 画面の左右すみの丸ボタン（盤面の高さを削らないよう浮かせて配置）。
- 試作では毎回2個ずつ配る（`ITEM_START`）。**本体に入れるときはガチャの在庫を読む**。

### 応援団（3Dボクセル）
- **オトン・オカーン・チッチ・ジェイド**の4人が、盤面の下のステージで常時わちゃわちゃしている。
- ドット絵（1ドット＝1ボクセル）を立体化。目・くちばし・鼻は手前に出っぱらせて奥行きを作っている。
  描画はブロックと同じインスタンシングに相乗りなので、**ドローコールは増えていない**。
- ときどき勝手にジャンプ／横に走る／くるっと回る。ライン消しで全員が跳ねて「バンザイ」ポーズに変わる。
  ハードドロップすると、落とした列に一番近い子だけがぴょんと跳ねる。
- ピンチ（上4行）になるとソワソワが速くなる。ゲームオーバーはうなだれる。
- **盤面には絶対にかぶらない高さまでしか跳ばない**（ジャンプ量に上限をかけている）。

### 子ども向けに守っていること
- 盤面のグリッド線は**常時表示**（3Dでも列を数えられるように）
- ゴーストは常時ON＋着地する列の床が光る
- アクティブな駒が**常に一番明るい**
- 全画面フラッシュは80msまで。純白はパーフェクトクリアだけに使う
- 明滅は2Hz以下
- **「✨演出」トグル**で、シェイク45%・ブルーム減・色収差ほぼ切・グレイン0・衝撃波オフにできる

### やりとり（postMessage）
| 向き | メッセージ | 意味 |
|---|---|---|
| 子→親 | `t2-ready` | 起動した。親はニックネームを返す |
| 親→子 | `t2-name` | 本体のニックネームをランキングの名前に使う |
| 子→親 | `t2-start-request` | プレイを始めたい（「ゲームスタート」「もう一回！」を押した） |
| 親→子 | `t2-start-ok` / `t2-start-deny` | 遊び券3枚を消費できたか |
| 子→親 | `t2-score` | ゲームオーバーのスコア → `saveGameScore('tetris2', …)` |
| 子→親 | `t2-exit` | 「‹ もどる」→ 親が iframe を `about:blank` にして息抜きメニューへ |

- **1プレイ＝遊び券1まい**（2026-08-20・3まい→1まいに変更。他の息抜きゲームと同じ枚数にそろえた）。入口では消費せず、実際に始めるたびに引く（リトライも1まい）。
- 券が3枚未満のときはカードを押しても入れない（トーストでお知らせ）。
- 戻るときに iframe を空にするので、音もrAFも確実に止まる。

## 監査で見つけて直したもの

一流ゲームクリエーターの体験監査と、QAリードの実装監査を1回ずつ通した。主な指摘と対応：

| 指摘 | 対応 |
|---|---|
| **🔴 ヒットストップ中に「おとす」を2連打するとタブが固まる**（溜めた入力を処理中に積み直して無限ループ） | 先に `splice(0)` で取り出してから流すように修正。1000回連打の実測で生存を確認 |
| **回転を連打すると駒が永久に固定されない**（壁蹴りで浮くたびに猶予が戻る） | 15回の上限を「浮いたとき」にも効かせた。実測 1.08秒で固定 |
| **NEXT/HOLD の3D駒がCSSの `backdrop-filter` でぼかされて読めない** | HUDのぼかしを削除。次に来る駒がはっきり読めるようになった |
| 背景のグリッドが数式上ほとんど描かれていない（ただの霧だった） | 奥行き係数を見直して、収束する床グリッドが出るようにした |
| ピンチなのに画面が何も変わらない（黒に係数を掛けても黒） | 加算に変更＋**デッドライン（赤い線）**を盤面に追加 |
| シングルもテトリスも同じ文字・同じ白飛び＝段差がない | 段数で文字の大きさ・色・白飛び量・破片の数と速さを変えた |
| ライン消しが「全部いっぺんに白」 | **光が左から右へ走り抜け、通ったセルから砕ける**方式に変更 |
| 起動タップで605ms固まる（リバーブ生成） | タイトル表示中に先に作るようにした（実測 3.2ms） |
| iOSでバックグラウンドから戻ると音が戻らない | `visibilitychange` で復帰。離れたら自動ポーズ |
| ゲームオーバー直後の141msに連打すると結果を見ずに再開 | 結果パネル表示から400ms後にだけ受け付ける＋操作パッドを隠す |
| 拍と映像が同期していない | キックの発音時刻を映像に渡し、**背景・レール・ブルームが4つ打ちで脈打つ** |
| ライン消しアニメ中に穴マーカーが4マスずれる／難易度別DAS/ARRが使われていない／`lockFlash`の線形検索 | すべて修正 |

## 既知の制約
- ヘッドレスChromium（SwiftShader）では12fps前後しか出ない。実機のGPUでの計測が必要。
- 実機iPhoneでの60fps確認はまだ。`EXT_color_buffer_half_float` を潰した状態でも RGBA8 にフォールバックして正常に動くことは確認ずみ。
- パーフェクトクリアの点数は、ライン消し点に**上乗せ**している（ガイドラインより多い）。子ども向けにご褒美を厚くする意図。変えるなら `core.js` の `if (perfect)` の行。
- `setPointerCapture` 中は `pointerleave` が飛ばない端末がある（ボタンから指をずらしても押しっぱなし扱いになる可能性）。実機で要確認。
